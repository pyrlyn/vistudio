## Limits

No Kotlin backend is bundled. The official 263.7084.0 backend is tested for local Gradle/JVM source navigation ordinary launch/breakpoint/step/Locals debugging, and the Watch/Immediate expressions listed above. Other backend versions, remote attach, test debugging, virtual/library-source navigation, terminal input, advanced Kotlin expressions, coroutines and inline source mapping are not claimed tested. Native F5 providers are implemented; native Build menu integration remains outside scope. The Gradle Error List publisher supports recognized Kotlin diagnostic headlines; multiline context and unrecognized compiler/plugin output remain in Output. Errors from the adapter's later Gradle run are shown in Debug Output. Cancellation and workspace-change cleanup are implemented; parser/process portions are covered by regression checks, while the IDE checks above cover build gating, source navigation, normal completion and Stop Debugging. The TextMate grammar provides lexical coloring rather than full Kotlin parsing. Windows process jobs cover the launched process and descendants created after assignment; startup uses Process.Start followed immediately by job assignment, not suspended native process creation. Extremely early detached children are therefore not guaranteed to be tracked. Gradle is run with `--no-daemon` to avoid sharing a persistent build daemon.
