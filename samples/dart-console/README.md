# Dart console sample

A pure Dart package for the Vistudio Dart integration: `bin/dart_console.dart` (entry point), `lib/` (shapes) and
`test/` (package:test unit tests). Open this folder with **File > Open > Folder**, then use **Tools > Dart**: Run,
Debug (F5 on `bin/dart_console.dart`), Run Unit Tests, or the Run | Debug CodeLens above `main` and each test.
