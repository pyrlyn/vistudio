# Flutter sample

A Flutter app for the Vistudio Dart integration (created with `flutter create --platforms windows`, Flutter 3.50):
`lib/main.dart` (counter app), `test/widget_test.dart` (widget test) and `integration_test/app_test.dart`
(integration test on a device). Open this folder with **File > Open > Folder**, then use **Tools > Dart**:
Run (flutter run on the device from the Dart toolbar, Windows by default), Flutter: Hot Reload / Hot Restart (or save a
.dart file while the app runs), Debug, Run Unit Tests and Run Integration Tests. Windows desktop needs the Visual
Studio "Desktop development with C++" workload.
