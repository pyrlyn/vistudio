# zig-hello

Minimal Zig 0.16 project for the Vistudio Zig features: open this folder with File > Open > Folder.

- `zig build -l` lists `install`, `uninstall`, `run` and `test`.
- `src/main.zig` and `src/shapes.zig` exercise completion, go to definition, references and CodeLens through ZLS.
- Break a line (for example remove a `;`) to see `zig ast-check` squiggles and Error List entries.
